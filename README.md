# Build a clean, modern, and minimal web app for an online car marketplace startup

Build a clean, modern, and minimal web app for an online car marketplace startup.



Main idea:

Users can browse cars, choose a car, apply for credit online, and request home delivery.



Design style:

- Very simple and clean (like Apple / Kaspi style)

- White background

- Minimal colors (black, white, light gray, one accent color - blue)

- Modern UI with rounded corners

- Mobile-first design

- Smooth and fast UX



Pages:



1. Home Page:

- Search bar (brand, price, year)

- Featured cars

- Categories (SUV, Sedan, Electric, etc.)

- Simple header with logo and login button



2. Car Listing Page:

- Grid of cars

- Filters (price, brand, year, mileage)

- Clean cards with image, price, monthly payment



3. Car Detail Page:

- Large car images

- Price + monthly credit payment

- “Apply for Credit” button

- “Chat with dealer” button

- “Order Delivery” button

- Car specs (year, engine, mileage)



4. Credit Application:

- Simple form (name, phone, income)

- Progress indicator

- Confirmation screen



5. Chat UI:

- Simple messenger style

- Clean bubbles

- No phone numbers visible



6. Dealer Dashboard (simple):

- Add car

- Upload images

- See requests



Features:

- Responsive design

- Fast loading

- Simple animations

- Focus on UX, not complexity



Important:

Keep everything VERY simple, clean, and startup MVP level.



No complex backend needed — focus on UI and flow.

Make it look like a billion-dollar startup product.

Focus on simplicity and trust.
